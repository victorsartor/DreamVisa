# ✈️ DV Visa | Assessoria de Vistos Premium

> **Solução web desenvolvida para assessoria especializada em vistos de turismo, renovações e reversões.**

Este projeto foi desenvolvido sob demanda para uma cliente real (DV Visa), com o objetivo de criar uma presença digital profissional e facilitar o contato de novos clientes com o serviço de consultoria.

---

## 🚀 O Projeto

O foco principal foi criar uma interface **Clean** e **Premium**, que transmitisse a confiança necessária para um serviço de assessoria de vistos. O site é totalmente responsivo e otimizado para conversão direta via WhatsApp.

* **Status:** ✅ Produção
* **Live Demo:** [https://dream-visa-self.vercel.app](https://dream-visa-self.vercel.app)

## 🛠️ Tecnologias Utilizadas

Para garantir performance e uma boa experiência de desenvolvimento, utilizei:

* **HTML5 & CSS3:** Estrutura semântica e estilização moderna com foco em mobile-first.
* **JavaScript:** Implementação de componentes interativos e lógica de navegação.
* **Vercel:** Deploy e gerenciamento de infraestrutura em nuvem.
* **Gemini** Como consultor de código e me auxiliar nas correções de bugs.

## 📈 Propósito e Aprendizado

Desenvolver o site da **DV Visa** foi uma oportunidade de aplicar conhecimentos de design focado em conversão e entender as necessidades reais de um negócio em crescimento. O projeto valida habilidades de:
1. Comunicação com o cliente e levantamento de requisitos.
2. Design de interface (UI) voltado para o mercado de luxo/assessoria.
3. Deploy e otimização para ambientes de produção.
